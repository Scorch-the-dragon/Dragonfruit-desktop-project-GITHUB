# Notes the pet can bring

Place plain UTF-8 `.txt` files directly in this folder. The Bring a note event
rescans the folder each time, so adding or editing a note does not require a restart.
Files are displayed literally in a read-only window; they are never executed or modified.
The window can be moved, resized, scrolled, and closed after delivery.

The pet randomly picks a note and either the left or right side of the screen.
Both random events and Shenanigans > Bring a note can trigger delivery.
Every delivery opens a new note window. Earlier notes stay open until you close them.
An empty folder produces a helpful note explaining where to put files.
For very large files, only the first 256 KiB are shown.

When distributing an exported game, copy this PetNotes folder beside the executable.
The exported app reads that external folder so people can add their own files.
